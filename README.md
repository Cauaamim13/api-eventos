Painel de Clientes - CRUD Full-Stack
Um sistema completo (CRUD) de gerenciamento de clientes com uma interface moderna, responsiva e conectada a um banco de dados relacional.

Este projeto foi desenvolvido dividindo a arquitetura em duas partes: uma API REST no Back-end e uma interface dinâmica no Front-end (Single Page Application).

🚀 Tecnologias Utilizadas
Front-end
React (com TypeScript)

Vite (Build tool super rápido)

Tailwind CSS v4 (Estilização utilitária e moderna)

Axios (Comunicação HTTP com a API)

Back-end
Node.js

Express (Criação de rotas da API)

MySQL (Banco de dados relacional)

CORS (Liberação de segurança entre portas diferentes)

⚙️ Funcionalidades
[x] Create: Adicionar novos clientes (Nome Completo, CPF, E-mail e Telefone).

[x] Read: Listagem dinâmica dos clientes em formato de tabela elegante com status.

[ ] Update: (Em desenvolvimento) Edição de dados de clientes existentes.

[x] Delete: Exclusão de registros com confirmação de segurança.
